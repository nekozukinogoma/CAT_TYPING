猫タイピング ルールなど (cats-typing rule etc.)

<使い方>
このゲームはタイピングをして猫を保護していくゲームです。
ねこは一単語/文章を打つごとに一匹保護します。
1分間タイピングして、保護した猫の数を数えます。

<その他>
コードはgoogle geminiを使用して作成しました。
index.htmlのファイルと写真のみでうごいています。
フォルダから写真を出したら写真が読み込まれなくなります。
なお、google geminiに命令するために使用した写真や、ゲーム内に入っている写真は
chat gptを使用して生成しました。

<How to use>
This is a game where you type to Keep as a cats.
You rescue one cat for every word or sentence you type.
Type for one minute, then count the number of cats you've rescued.

<Other Notes>
The code was created using Google Gemini.
The game runs using only the index.html file and the images.
If you remove the images from the folder, they will no longer load.
Note that the images used to give commands to Google Gemini, as well as the images included in the game,
were generated using ChatGPT.
